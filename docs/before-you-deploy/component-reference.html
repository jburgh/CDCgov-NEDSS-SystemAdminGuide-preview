    NBS 7 component reference

    The pages in this section describe each component in NBS 7. Use it to understand what each component does, why it is included in your deployment, and how it relates to other components.

    NBS 7 is deployed in phases. Components in this reference are organized by deployment phase:

    • NBS 7 core deployment
    • Real-Time Reporting (RTR) deployment
    • Data Ingestion (DI) API deployment

    For deployment configuration details including configuration parameters, Helm chart values, and step-by-step setup instructions, see the Deploy NBS 7 section of this guide.

    Quick reference

    The following table shows which components are included in NBS 7. RTR and DI API are deployed separately from the core NBS 7 components.

    Component NBS 7 RTR DI API
    Legacy NBS 6 ✓    
    NBS Modernization API ✓    
    NBS Web UI ✓    
    NBS Gateway ✓    
    Elasticsearch ✓    
    Nifi ✓    
    Keycloak ✓    
    Database (NBS_ODSE, NBS_SRTE) ✓    
    Infrastructure and networking layer ✓    
    Debezium   ✓  
    Kafka and Kafka Connect   ✓*  
    RTR domain services   ✓  
    DI API     ✓

    *Jurisdictions that deploy RTR but continue with batch reporting instead of using the real-time benefit might not need Kafka and Kafka Connect.
